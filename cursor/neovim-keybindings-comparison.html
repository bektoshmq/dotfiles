Scope, interpretation, and source files

“All mappings” here means the meaningful custom and inherited mappings from the active runtime. Stock Vim’s full operator/motion grammar is treated as the VSCodeVim baseline instead of expanding hundreds of standard combinations into separate rows.

  • Native: VSCodeVim or Cursor already provides substantially the same behavior.
  • Exact port: a stable Cursor command exists and can be assigned to the same key.
  • Approximation: a useful Cursor action exists, but semantics differ.
  • Extension: an additional Cursor extension would be required.
  • No equivalent: the feature depends on Neovim, its plugin runtime, or Herdr.
